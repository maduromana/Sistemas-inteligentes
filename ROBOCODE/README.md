# RoboFlex - Robocode

Projeto desenvolvido para a disciplina **Sistemas Inteligentes**, utilizando a plataforma **Robocode**.  
O RoboFlex é um robô de batalha capaz de participar de duelos **1x1** e batalhas **all x all**.  

---

## Descrição

- Desenvolvido em **Java** para a plataforma **Robocode**.  
- Implementa estratégias de movimentação e ataque baseadas em regras definidas durante a disciplina.  
- Teve **bom desempenho no modo all x all**, obtendo resultados positivos contra os robôs criados por outros alunos.  

---

## Conteúdo do Repositório

| Arquivo/Extensão | Descrição |
|------------------|-----------|
| `.java`          | Código-fonte do robô |
| `.class`         | Arquivo compilado do robô para execução no Robocode |
| `.pdf`           | Relatório com estratégias, justificativas e desempenho nas batalhas |

---

## Como Executar

1. Baixe e instale o **[Robocode](https://robocode.sourceforge.io/)**.  
2. Copie os arquivos `.java` ou `.class` para a pasta `robots` do Robocode.  
3. Abra o Robocode e inicie uma batalha:  
   - **1x1** contra outro robô.  
   - **All x All** para múltiplos robôs.
